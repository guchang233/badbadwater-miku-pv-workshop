# 我的悲伤是水做的 · 初音未来高清重制

片源：本次上传的 175348148-1-208.mp4，1920×1080，5422 帧，约3分46秒。
成片画布1920×1080，24 fps，H.264 High / yuv420p，原片AAC直接流复制。
初音担任画面主角，演唱仍为原片洛天依原唱。

全部32张人物绘稿根据本次高清原帧重新生成，未采用旧版人物PNG。
使用内置 imagegen，另有两次无字清理。原绘稿输出1672×941，按完整画布适配到1080p画布。
身份基准：低饱和青绿色双马尾、青绿色/原片简化深色眼睛、深蓝粉色发饰。
服饰延续原作雨衣及室内短袖短裤。鱼缸头演奏者是保留的配角。

合成以原片手部、衣物、道具和场景为基线，主要替换脸、头发及相关遮挡。
场景、歌词、鸟群、白色水花及其他独立效果沿用当前高清源帧的时间。
source_specs.json和timeline.json记录半开曝光区间；源片5422个真实PTS另存于analysis/pts.json。
源PTS量化到毫秒，与24fps网格最大差约0.333毫秒。没有新增动作中间稿或光流/非刚性形变。
原有叠化根据原人物头部差值估计权重；新增长发跟随同一来源透明度。
密集鸟群沿用前镜头人物层，并按当前原帧恢复前景鸟群。
近景歌词使用原片前景文字掩膜；切换歌词前先从基础差值中移除旧文字，避免反色残影。白色圆形效果独立于原角色白发。

各镜头绘稿与原片进行了静帧结构对照；另检查编码后抽帧及转场边界。
完整解码、尺寸、帧数、时长和音轨字节校验见validation.json。
未进行实际播放器原速观感验收。局部线条、双马尾体积、玻璃边界与原稿仍可能有细微差异。
生成稿的背景有轻微纹理，在合成中根据限定区域的背景色与语义掩膜恢复原作底色。
不声明角色像素精确锁定或全部背景像素在有损编码后完全相等。

## 重建

依赖：Python numpy、scipy、Pillow，ffmpeg / ffprobe。
在工程根目录运行：

```bash
python work_hd/compose_hd.py --render
python work_hd/build_comparison.py
python work_hd/verify_delivery.py
```

refs保存生成时使用的高清原帧；assets保存采用PNG、完整prompt和职责明确的参考顺序。
所有人物素材均以原片画布坐标配准，没有按人物包围盒自动居中。
带声转场短片覆盖原曲3:28–3:42，包含结尾转头、叠化和淡出。

以delivery_manifest.json中的32项为采用清单；带_with_text名称的文件只是清理前记录。最终近景经过局部修正，并在完整成片上重新编码一次；复建直接运行compose_hd.py即可得到同一合成逻辑。
