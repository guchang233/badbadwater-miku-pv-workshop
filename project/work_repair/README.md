九处修复合集：左上一版MIKU，右修正版，共约62秒，含各问题所在镜头与相邻内容；为剪辑合并，原曲片段AAC重新编码。focus_segments.json记录原曲时间区间。

## 重建

解压后的项目保留原片、此前成片基线、此前高清工程、4张新稿及生成记录。依赖Python numpy、scipy、Pillow，ffmpeg和ffprobe。

在解压目录运行：

```bash
python work_repair/render_repair.py
python work_repair/build_comparison.py
python work_repair/review_encoded.py
python work_repair/verify_delivery.py
```

原始曝光表在work_hd/source_specs.json；最终曝光表在work_repair/final_exposures.json。pier_exposures.json和pier_states.json明确记录三张背向姿态的源帧切换。最终素材映射在delivery_manifest.json。旧绘稿及旧曝光表保留，便于追踪本次更改。

合成根据原片帧索引进行，头发使用生成稿，水面、杯子、鸟、栏杆、歌词和标记按各自前后层恢复。灰色背景采用源背景样本，不再把半透明衣物描边当作纸色。手工多边形规定角色图层的归属，其邻近范围内的实际青绿色发束轮廓可扩展遮罩，避免矩形切断发束。
